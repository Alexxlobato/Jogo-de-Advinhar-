# 🎮 Jogo de Adivinhação

Um jogo simples onde o usuário tenta adivinhar um número de 1 a 10.

## 🚀 Tecnologias
- HTML
- JavaScript

## 🎯 Funcionalidades
- Número aleatório
- Dicas (alto/baixo)
- Limite de tentativas

## 📚 Aprendizados
- Condições (if/else)
- Manipulação do DOM
- Lógica de programação
